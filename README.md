# База занятий по репетиторству

## Описание

Проект реализует консольную базу данных для учёта занятий по репетиторству.
Данные хранятся в оперативной памяти во время запуска программы.

Одна запись содержит:

- `id` занятия;
- имя ученика;
- предмет;
- дату занятия;
- стоимость.

## Возможности

- добавление занятия;
- просмотр всех занятий;
- поиск занятий по одному или нескольким полям;
- обновление занятия по `id`;
- удаление занятия по `id`;
- сортировка записей по выбранному полю в прямом или обратном порядке;
- обработка ошибок при неправильном вводе.

## Лабораторная работа 4

Работа выполнена поверх лабораторной работы 3 (`task3`).

Учтённые замечания:

- **Сообщение при некорректном числовом вводе в TUI.** Раньше выводилось
  обезличенное `"Ошибка: введите целое число."`. Теперь сообщение
  показывает, что именно ввёл пользователь, и подсказывает попробовать
  ещё раз: `"Ошибка: «text» не является целым числом. Попробуйте ещё раз."`
  (см. `LessonTUI._read_int`).

- **Валидация записей при инициализации `LessonDatabase`.** В предыдущей
  черновой версии код инициализации ошибочно вызывал несуществующий метод
  `self.add(record)`, из-за чего создание базы с начальным набором записей
  (`LessonDatabase(records=[...])`) приводило к `AttributeError` и падало
  ещё до первой проверки. Это осталось незамеченным, так как не было теста
  на инициализацию с данными. Исправление:
  - добавлен приватный метод `_add_validated`, который выполняет ту же
    проверку (`id`, стоимость, непустые поля, дубликаты `id`), что и
    `create_record`;
  - и `__init__`, и `create_record` теперь используют этот единый метод,
    поэтому исключается дублирование логики валидации и повторение
    подобной ошибки;
  - добавлены тесты `test_init_accepts_valid_initial_records`,
    `test_init_validates_initial_records`,
    `test_init_rejects_duplicate_id_in_initial_records`,
    `test_init_with_no_records_creates_empty_database`.

- **Удалён устаревший код совместимости с лабораторной работой 2.**
  Модульные функции-обёртки (`create_record`, `select_record`,
  `update_record`, `delete_record`, `sort_records` на уровне модуля,
  работавшие через `default_database`) удалены из `memory.py`: вся
  функциональность доступна через класс `LessonDatabase`, а
  `default_database` используется только как база по умолчанию для
  `LessonTUI`.

- **Проверены автоматизированные тесты.** Полный набор тестов (22 теста)
  проходит успешно, добавлены недостающие тесты на валидацию при
  инициализации, покрытие подтверждено пакетом `coverage`.
