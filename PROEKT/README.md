КОНСОЛЬНАЯ БАЗА ДАННЫХ
=======================

Программа представляет собой консольную систему управления базами данных 
с поддержкой нескольких таблиц, различных типов данных и автоматическим сохранением.


СТРУКТУРА ПРОЕКТА
-----------------

my_project/
│
├── backend/                    # Бэкенд часть (логика работы с данными)
│   ├── __init__.py             # Маркер пакета Python
│   ├── database.py             # Классы Table и Database (ядро БД)
│   ├── sorters.py              # Классы для сортировки данных
│   └── memories.py             # Сохранение/загрузка в JSON
│
├── frontend/                   # Фронтенд часть (пользовательский интерфейс)
│   ├── __init__.py             # Маркер пакета Python
│   └── console.py              # Консольный интерфейс (все диалоги)
│
├── data/                       # Папка с сохранениями (создается автоматически)
│   └── database.json           # Файл с данными всех таблиц
│
└── start.py                    # Точка входа в программу


НАЗНАЧЕНИЕ МОДУЛЕЙ
------------------

backend/database.py
- Table - класс для отдельной таблицы:
  * columns - список названий столбцов
  * column_types - типы данных столбцов
  * rows - данные таблицы
  * row_ids - уникальные ID строк
  * deleted_rows - корзина удаленных
  * row_history - история изменений
  * search_index - поисковый индекс

- Database - класс для управления несколькими таблицами:
  * tables - словарь таблиц
  * current_table - имя текущей таблицы

backend/sorters.py
- sort_by_column() - сортировка по одному столбцу
- sort_multiple_columns() - сортировка по нескольким столбцам
- filter_by_value() - фильтрация по значению

backend/memories.py
- save() - сохраняет все таблицы в JSON
- load() - загружает таблицы из JSON
- auto_save() - автосохранение после изменений

frontend/console.py
- print_table_with_selection() - отрисовка таблицы с подсветкой
- run() - главный цикл программы
- диалоговые методы для каждой команды

start.py
- точка входа, создает и запускает интерфейс


ЗАПУСК ПРОЕКТА
--------------

1. Открой терминал/командную строку
2. Перейди в папку с проектом: cd my_project
3. Запусти программу: python start.py


КОМАНДЫ УПРАВЛЕНИЯ
------------------

Работа с таблицами:
T1 - Создать новую таблицу
T2 - Переключиться между таблицами
T3 - Переименовать таблицу
T4 - Удалить таблицу
T5 - Создать тестовую таблицу с демо-данными
S  - Сохранить данные вручную

Работа с данными:
1  - Выбрать строку по номеру
2  - Выбрать столбец по номеру
3  - Редактировать выбранную ячейку
4  - Добавить новый столбец
5  - Добавить новую строку
6  - Удалить выбранную строку
7  - Удалить выбранный столбец
8  - Сортировать по выбранному столбцу
9  - Сбросить выбор строки/столбца
10 - Поиск по значению
11 - Показать статистику
12 - Восстановить последнюю удаленную строку
13 - Показать историю изменений
0  - Выход (с сохранением)


СОХРАНЕНИЕ ДАННЫХ
-----------------

Как сохранить:
1. Автоматически - после каждого изменения
2. Вручную - команда S
3. При выходе - команда 0

Где сохраняется:
- Файл: data/database.json
- Формат: JSON
- Сохраняется: все таблицы, данные, история, настройки


ТИПЫ ДАННЫХ
-----------

Поддерживаемые типы столбцов:
- string - текстовые строки
- number - числа
- boolean - true/false
- list - списки значений


ПРИМЕР РАБОТЫ
-------------

1. Запуск программы: python start.py
2. Создание тестовой таблицы: T5
3. Выбор строки: 1
4. Выбор столбца: 2
5. Редактирование ячейки: 3 -> ввод "Новое значение"
6. Сортировка: 8
7. Сохранение: S
8. Выход: 0


ВОЗМОЖНЫЕ ПРОБЛЕМЫ
------------------

Проблема: Программа не сохраняет данные
Решение: Проверь что папка data существует и доступна для записи

Проблема: Не могу удалить текущую таблицу
Решение: Сначала переключись на другую таблицу (команда T2)

Проблема: Потерялся выбор строки/столбца
Решение: Используй команду 9 для сброса выбора
