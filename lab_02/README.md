# Лабораторная работа 2

## Описание

В лабораторной работе сделана небольшая база данных для учета занятий
по репетиторству. Она работает в оперативной памяти: записи лежат в списке
во время запуска программы и пропадают после выхода.

Одна запись содержит:

- `id` занятия;
- имя ученика;
- предмет;
- дату занятия;
- стоимость.

## Структура проекта

```text
lab_02/
├── README.md
└── src/
    └── db/
        ├── __init__.py
        ├── __main__.py
        ├── tui.py
        └── backend/
            ├── __init__.py
            └── memory.py
```

- `src/db/__main__.py` - файл запуска.
- `src/db/tui.py` - меню в консоли.
- `src/db/backend/memory.py` - добавление, поиск, изменение и удаление записей.

## Реализованные функции

- добавление занятия;
- просмотр всех занятий;
- поиск занятий по одному или нескольким полям;
- обновление занятия по `id`;
- удаление занятия по `id`;
- обработка ошибок при неправильном вводе.

Пример записи:

```text
1. Ученик: Иван, предмет: математика, дата: 25.04.2026, цена: 1200 руб.
```

## Запуск

Из папки `lab_02`:

```powershell
python -m src.db
```
